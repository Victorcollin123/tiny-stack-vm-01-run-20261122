A tiny stack virtual machine for make.fun's tiny stack ISA: it runs each program in `/input/<id>/` and writes its output and exit code to `/output/<id>/`. 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input and output, and all ten traps with their own exit codes.

Run: `node main.ts`
